# Bounty Digital website

Responsive static business website made with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website structure and content
- `styles.css` — dark navy and electric blue responsive design
- `config.js` — phone, WhatsApp and email details
- `script.js` — mobile navigation and contact actions

## Preview locally
1. Extract the ZIP.
2. Open the folder.
3. Double-click `index.html` to preview it in a browser.

## Publish with GitHub and Vercel
1. Create/sign in to GitHub and create a repository named `bounty-digital`.
2. Upload `index.html`, `styles.css`, `config.js` and `script.js` to the repository root.
3. Sign in to Vercel using GitHub.
4. Choose Add New → Project and import `bounty-digital`.
5. Choose the `Other` framework preset. Leave build command and output directory blank, then deploy.
6. Vercel will provide a public `*.vercel.app` website address. A custom domain can be connected later.

## Contact form limitation
The form opens the visitor's email application with a pre-filled message addressed to the business email. It does not save messages to a website inbox or database. A hosted form service or CRM can be connected later.

## Before launch
Test the phone, WhatsApp and email links on your phone. Update any wording that does not match your actual services. Only add genuine client projects and testimonials after you have them.
